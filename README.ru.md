# WinRust

**Windows-оболочка на Rust: быстрее и легче стандартной.** Небольшие нативные программы (без .NET, без Electron), которые заменяют части Windows: панель задач, Проводник, поиск файлов, диспетчер задач, а ещё чистильщик диска, карту диска и просмотрщик фото. Один установщик всё ставит, одна кнопка всё убирает.

[English](README.md) | **Русский**

<p align="center"><img src="assets/th.jpg" alt="WinRust" width="480"></p>

> **Сначала прочитайте.** WinRust отключает поиск Windows, прячет панель задач и может отключить Проводник как оболочку. Exe не подписан, поэтому SmartScreen покажет предупреждение. Перед установкой создаётся точка восстановления, но сначала попробуйте на запасной машине или в виртуалке.

## Установка

1. Скачайте `WinRust.exe` из [последнего релиза](https://github.com/iijawadm/WinRust/releases/latest) (Windows 10/11, x64).
2. Запустите от имени администратора.
3. Отметьте галочками нужные компоненты и нажмите кнопку установки. При первой установке `rust-explorer` не отмечен. Отметьте его, если хотите заменить оболочку Проводника Windows (или переключатель **Оболочка: rust-explorer** в шестерёнке строки topbar). Они ставятся в правильном порядке; упавший или пропущенный компонент не останавливает остальные, окно покажет, что пошло не так.

Поиск Windows необязателен: в урезанной Windows (например, LTSC-образ без службы Windows Search) этот шаг пропускается с предупреждением, а не ломает установку.

Если UAC просит пароль **другого администратора**, пользовательские настройки (автозапуск, задачи планировщика, профиль PowerShell, права поиска) всё равно записываются тому, кто вошёл в систему, а не введённому администратору. Если установщик не может определить этого пользователя, он останавливается, ничего не изменив.

**Обновление:** скачайте новый `WinRust.exe` со страницы релизов, запустите от имени администратора и выберите компоненты для обновления или установки. Если `rust-explorer` уже установлен, он по умолчанию отмечен для обновления. Ваши настройки и сохранённые исходные значения Windows остаются.

Установщик открывается на английском. Кнопка **Русский** в его углу (или «Программы WinRust на English» в меню панели по правому клику) переключает язык всех программ WinRust.

## Удаление и экстренное восстановление

- **В главном окне `WinRust.exe`** (изменяемый горизонтальный интерфейс): кнопки **Отменить**, **Восстановить** и **Удалить всё** всегда закреплены в нижней панели.
- **В WinRust Settings → Восстановление** (а также ярлык **WinRust Recovery** в меню Пуск и пункт в меню шестерёнки панели):
  1. **Отменить последнее изменение** — откатывает последнее записанное изменение WinRust.
  2. **Восстановить настройки Windows по умолчанию** — создаёт точку восстановления, безопасно останавливает оболочку WinRust (`rs-shell`, `reshell`, `topbar` с правами администратора, `rust-explorer --desktop`) и дожидается освобождения `Shell_TrayWnd`/`Progman`, возвращает Проводник Windows, параметры `Winlogon`, стандартную панель задач и исходную видимость значков рабочего стола, а затем **проверяет**, что Проводник и панель задач реально запущены (при сбое автоматически откатывается, чтобы избежать чёрного экрана; личные файлы не затрагиваются).
  3. **Полное удаление WinRust** — после подтверждения полностью удаляет все компоненты, задачи, автозапуск и перехваты WinRust.
  4. **Создать точку восстановления** — сохраняет снимок конфигурации с меткой времени (плюс системную точку Windows при запуске от администратора).
- **Независимое экстренное восстановление (если интерфейс завис или экран стал чёрным):**
  1. Нажмите **Ctrl+Alt+Del** → **Диспетчер задач** → **Запустить новую задачу** (отметьте *Создать задачу с правами администратора*).
  2. Выполните: `"%ProgramFiles%\WinRust\winrust-recovery.exe" emergency-restore --yes` (безопасное восстановление и проверка Проводника Windows), **либо** `winrust-recovery.exe rollback --yes` (полное удаление), **либо** `winrust-recovery.exe verify-shell` (диагностика оболочки).
  3. Если `winrust-recovery.exe` недоступен: запустите `explorer.exe` в Диспетчере задач или `"%ProgramFiles%\rust-settings\rust-settings.exe" --restore-defaults --yes`.
  4. Подробный журнал восстановления сохраняется в `%ProgramData%\WinRust\recovery\recovery.log`.
- По одному плагину: `plugin-launcher uninstall <плагин>` (см. [Командная строка](#командная-строка)).

При удалении `rust-explorer` восстанавливает настройки запуска служб и порог группировки svchost, сохранённые перед установкой. Если в старой установке копий нет, текущие значения сохраняются и появляется предупреждение.

| Плагин | Что вы получаете | Что меняется в Windows |
|---|---|---|
| **rust-search** | Поиск файлов по всем NTFS-дискам, Alt+Space. С topbar Win+R открывает его режим «Выполнить»: история, дополнение папок (Tab), Ctrl+Shift+Enter запускает от администратора | Отключается служба поиска Windows, блокируется SearchHost.exe, прячется строка поиска на панели |
| **rtaskmgr-win32** | Диспетчер задач (Ctrl+Shift+Esc открывает его) | Запуск `taskmgr.exe` перенаправляется на него (системный файл не трогается). Заодно ставится чистильщик диска **rs-du**. На странице **«Ускорение»** обратимые переключатели, всё по желанию: профили «Игра» и «Работа» (останавливают фоновые службы включая SysMain, закрывают синхронизацию или лаунчеры, переключают схему питания на High/Ultimate Performance, чистят кэш standby и блокируют Win в играх, затем всё возвращают), **Авторежим «Игра»** (topbar обнаруживает полноэкранные игры, поднимает приоритет, отключает EcoQoS, включает таймер 0,5 мс и максимальную производительность от сети), **блокировка Win** в играх (`Win+Shift+G`), **игровые настройки Windows** (HAGS, Игровой режим, без Game DVR, приоритет GPU/ЦП в MMCSS и снятие сетевого троттлинга), очистка кэша standby (сейчас или автоматически), блок процессов Пуска/виджетов/«Связи с телефоном», еженедельный `winget upgrade`, исключения Defender для кэшей сборки и библиотек Steam/Epic/Xbox/GOG/EA/Ubisoft/Riot/Battle.net, быстрее NTFS, блокировка рекламы через hosts. В меню **«Ядра процессора»**: все ядра, первая половина (CCD0 / P-ядра), без ядра 0 (анти-статтер) и только чётные ядра (без SMT/HT). **«Автозагрузка»** показывает задачи и сторонние службы с вкладом во время загрузки. **«Что тормозит»** показывает DPC/прерывания, зависшие окна, медленный диск и время загрузки. Удаление всё возвращает |
| **topbar** | Нижняя панель в стиле Windows 11: окна, часы, адаптивные быстрые настройки Ethernet/Wi-Fi/Bluetooth, громкость, визуальная полоса прокрутки и выбор вывода звука, выравнивание слева или по центру, меню | Стандартная панель задач прячется; при полноэкранной игре опрос и перерисовка GDI+ приостанавливаются. Показывает Ethernet и скорость соединения в углу и быстрых настройках, автоматически скрывает плитки Wi-Fi и Bluetooth при отсутствии адаптеров, скрывает стрелку трея когда скрытых значков нет, показывает визуальную шкалу громкости при прокрутке колеса мыши и выпадающий список устройств вывода звука под ползунком громкости (правый клик по динамику также открывает меню устройств). Меню шестерёнки разбито на страницы: «Тема», «Цвета и прозрачность», «Шаблоны», «Панель» (край, размер, автоскрытие, кнопки слева, скрытие значков рабочего стола, Alt+Tab по монитору, Авторежим «Игра», блокировка Win) и «Сбросить всё по умолчанию». Заодно ставятся **reshell** (хоткеи: Win+Ctrl+1/2/3 и Win+\` переключают рабочие столы, Win+1..9 открывают кнопки панели, Win+D рабочий стол, Win+I Параметры, Win+E Проводник Windows; Win+Shift+G блокировка Win в играх; возвращает панель задач, если topbar упал), **rs-du** и блок в профиле PowerShell (`zoxide`, `grep`=rg, `ll`=eza, `cat`=bat; молчит, если их нет) |
| **rust-explorer** | Самостоятельный файловый менеджер с вкладками, собственным ZIP-движком (`.zip` открывается как папка) и рабочим столом | Работает независимо рядом с Проводником Windows, не перехватывая его ассоциации и `Win+E`. ПКМ по рабочему столу позволяет скрывать, сортировать, упорядочивать и менять размер значков. Своё копирование (на SSD несколько файлов сразу, большие файлы без кэша, прогресс в строке состояния), **«Compress to ZIP»** / **«Extract here»** (ZIP и 7z), группировка по дате и кнопки мыши «назад / вперёд». Нужен topbar |
| **wiztree** | Карта занятого места на диске («WinRust Disk» в Пуске) | Ничего, кроме файла и ярлыка |
| **photoview** | Быстрый просмотр фото | Добавляется в «Открыть с помощью» (по умолчанию не назначается) |
| **rust-settings** | Параметры на Rust (одно окно): экран (разрешение, частота, ночной свет, расположение мониторов перетаскиванием), звук (устройства, громкость по приложениям), **Игры** (авторежим «Игра», блокировка Win, таймер 0,5 мс, Игровой режим Windows, отключение Game DVR, прямой ввод мыши без ускорения, отключение окна 5×Shift, разблокировка «Максимальной производительности»), схема питания, место на дисках и очистка, сетевые адаптеры, Wi-Fi на всех адаптерах (пароль или 802.1X), VPN и прокси, Bluetooth, приложения, Центр обновления, персонализация, **Восстановление** (отмена последнего изменения, возврат настроек Windows по умолчанию, полное удаление WinRust, создание точки восстановления), о системе | Одноэкземплярное окно (повторный запуск выводит существующее окно на передний план); создаёт ярлыки Settings и Recovery в Пуске. Win+I и меню панели открывают это окно вместо Параметров Windows |
| **debloat** | Отключает телеметрию, Copilot, Recall, рекламу в Пуске, фоновый Edge | Службы и политики реестра; старые значения сохраняются и возвращаются при удалении. **Только из командной строки:** `install debloat --yes` (группы: `updaters`, `defender`, `ntfs`, `dns`, `gaming`) |

## Стили

Шестерёнка в левом краю панели открывает **Настройки панели**; стиль, выбранный на странице **Тема**, сразу применяется к панели, файловому менеджеру (rust-explorer) и окну поиска (Alt+Space):

| Стиль | Как выглядит |
|---|---|
| **Обычный** | Синий, как в Windows 11, панель внизу |
| **Терминал** | Зелёный на чёрном, шрифт Consolas, прямые углы |
| **Плавающий док** | Панель-пилюля по центру; развёрнутые окна занимают весь экран, док уезжает из-под них и возвращается у нижнего края |
| **Тайлинг** | Тонкая панель сверху, янтарный акцент, скругления как в Обычном; «Разложить окна плиткой» ставит открытые окна рядом |
| **Белая дорога** | Цвет слоновой кости с золотом: еле заметные треугольники, часть с золотой обводкой, за панелью, её окошками и rust-settings |
| **Рубин** | Глубокий гранатовый цвет с ярким рубиновым акцентом: плавный градиент сверху вниз с мягким глянцем, за панелью и её окошками |

В меню шестерёнки также выбирается положение панели (снизу, слева или справа: боковая панель показывает только значки, окошки открываются рядом с ней) и автоскрытие.

Выбор хранится в `%ProgramData%\WinRust\style.txt`.

## Бенчмарк

Одноразовые замеры на одной машине (Windows 11 IoT Enterprise 10.0.26300, RTX 4060 Laptop, NTFS). Это порядок величин, а не лабораторные цифры.

| Что | Windows | WinRust | Разница |
|---|---|---|---|
| Поиск файла (rust-search по всему C: против `dir /s` по одной папке) | 8 340 мс | 45 мс | быстрее на **99,5%** |
| То же против `Get-ChildItem -Recurse` | 16 200 – 28 600 мс | 45 мс | быстрее на **99,7–99,8%** |
| Открыть окно с папкой (rust-explorer, медиана 5 запусков) | 420 мс | 60 мс | быстрее на **86%** |
| Память оболочки (topbar + rust-explorer + rs-shell + reshell против explorer.exe) | 366 МБ | 46 МБ | меньше на **87%** |
| То же вместе с индексом поиска (53 МБ) | 366 МБ | 99 МБ | меньше на **73%** |
| Размер файлового менеджера (теперь с ZIP и 7z внутри) | 3 280 КБ | 1 179 КБ | меньше на **64%** |
| Размер диспетчера задач | 5 791 КБ | 954 КБ | меньше на **84%** |
| CPU панели в простое (topbar после оптимизации, % одного ядра) | 0,00–0,10% (explorer) | 0,05–0,10% | на уровне Проводника |
| Копирование 5000 мелких файлов, ~160 МБ (rust-explorer: IFileOperation, движок Проводника, против своего копирования) | 16,3 с | 2,3 с | быстрее на **86%** (в 7 раз) |
| Копирование одного файла 1 ГБ (то же) | 0,58 с | 0,60 с | одинаково |
| Упаковка тех же 5000 файлов в ZIP (`Compress-Archive` против «Compress to ZIP» в rust-explorer) | 48,4 с | 0,75 с | быстрее на **98%** (в 64 раза) |

В сумме: **по скорости и размеру быстрее или меньше на 64–99%, по CPU в простое и копированию одного большого файла равны.** Оговорки: rs ищет по готовому индексу MFT (за это платит 53 МБ памяти), а `dir` и PowerShell обходят диск заново; explorer.exe при замере всё ещё работал и держал окна, поэтому выигрыш по памяти немного завышен; поиск Windows и диспетчер задач не сравнивались. Копирование и ZIP (`cargo test -p rust-explorer --release bench -- --ignored`) мерились один раз на только что записанных файлах, поэтому обе стороны читали из кэша памяти; наш ZIP чуть больше (0,9 МБ против 0,7 МБ), потому что каждый файл сжимается на своём ядре отдельно.

## Для разработчиков

### Структура
```
src/            установщик (plugin-launcher.exe)
  main.rs         таблица плагинов PLUGINS: имя, тексты, пара install/uninstall, значок
  install/        что каждый плагин меняет в системе и как это откатывается (файл на плагин)
  cli.rs, ui.rs   командная строка и окно; оба вызывают одни и те же функции установки
common/         winrust-common: переключатель языка (t!/tf!), стили и палитры, разбор вывода reg.exe, чтение MFT
plugins/        исходники всех плагинов, каждый отдельный crate
ReShell/        reshell (хоткеи рабочих столов, страховка topbar), ставится вместе с topbar
payload.txt     какие exe вшиваются в установщик и где их кладёт сборка
payload/        эти exe после сборки (не в git)
scripts/        сборка, обновление, релиз
```
Всё собрано в один cargo workspace (один `Cargo.lock`, все exe в `target\release`). `plugins/rust-search` и `plugins/chrome-rs` собираются отдельно: им нужен `panic = "unwind"` (см. `Cargo.toml`).

### Сборка
Нужны Windows x64 и Rust stable (1.85+) с MSVC.
```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-all.ps1
```
Результат: `target\release\plugin-launcher.exe`, внутри все плагины. Закройте запущенный установщик перед сборкой. Тесты: `cargo test --workspace` (и `cargo test` в `plugins\rust-search`). CI делает то же самое при каждом пуше (`.github/workflows/build.yml`).

| Скрипт | Что делает |
|---|---|
| `build-all.ps1` | всё: плагины → `payload\` → установщик |
| `build-plugins.ps1` | только плагины → `payload\` (без пересборки установщика) |
| `update-plugin.ps1 <плагин>` | пересобрать и переустановить один установленный плагин без пересборки установщика (просит админа через UAC) |
| `user-mode.ps1`, `dev-update.ps1` | режим разработчика: topbar, rust-explorer, rs-shell и reshell запускаются из `%LOCALAPPDATA%` поверх Проводника и меняются без админа |
| `bench.ps1` | бенчмарк поиска и диспетчера задач |
| `publish.ps1`, `release.ps1` | коммит и пуш; релиз на GitHub с `WinRust.exe` |

### Командная строка
Из терминала **с правами администратора**:
```
plugin-launcher list
plugin-launcher install <плагин>... --yes (одно или несколько имён, либо `all` для компонентов по умолчанию; без --yes только покажет предупреждения)
plugin-launcher update <плагин>          (переустановить из payload\ рядом с exe)
plugin-launcher uninstall <плагин>
plugin-launcher rollback --yes           (удалить всё)
```

Чтобы включить `rust-explorer` в первую установку всех компонентов, выполните `plugin-launcher install all rust-explorer --yes`. Если `topbar` уже установлен, можно установить `rust-explorer` отдельно.
Несколько плагинов в одной команде ставятся в порядке таблицы (topbar раньше rust-explorer); упавший не останавливает остальные. Коды выхода: 0 успех, 1 ошибка (хотя бы один плагин не встал), 2 неверные аргументы или нет `--yes`. Без аргументов открывается окно. Журнал установки: `%ProgramData%\plugin-launcher\install.log`.

### Новый плагин
1. Crate в `plugins/<имя>`, добавить его в `members` корневого `Cargo.toml`.
2. Строка в `payload.txt`.
3. `src/install/<имя>.rs` с парой install/uninstall (и строка `mod` в `src/install/mod.rs`). Перед любым изменением сохраните исходные значения, чтобы удаление могло их вернуть.
4. Запись в `PLUGINS` (`src/main.rs`). Окно, его высота и командная строка подхватят её сами.
